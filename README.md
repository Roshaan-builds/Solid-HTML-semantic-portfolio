## 📋 What's Included

- **About Section** - A bit about who I am and what I'm learning
- **Skills** - Technologies and skills I'm working with
- **Projects** - A showcase of my projects (links to GitHub repos)
- **Contact** - Ways to reach me (email, GitHub, LinkedIn, etc.)

## 💻 Tech Stack

- HTML5
- CSS3
- Responsive Design (mobile-friendly)

## ✏️ How to Customize

1. Edit `index.html` directly on GitHub
2. Replace placeholder text with your actual info:
   - Your name and tagline
   - About section content
   - Skills list
   - Project descriptions and links
   - Contact information
3. Commit changes and they'll update automatically
